Untitled3.ipynb (Актуализация дат)
Преобразовывает исторические данные  в актуальные.
Скрипт считает CSV, сдвинет все таймстампы на текущую дату (с сохранением 5-минутных интервалов и маркером UTC Z) и сохранит обновленный файл (или передаст его дальше).

Untitled1 (2).ipynb (Симулятор данных)
Эмуляция работы CGM-датчиков и загрузка данных в бэкенд.
Скрипт разделен на две части, чтобы имитировать существующих пользователей с историей и новых пользователей без истории, только live-поток, предотвращает перегрузку ML-моделей.
Функция upload_history_filtered() сработает корректно только если ты уже выполнены ячейки конфигурации выше. Если ты запустить её в пустом ядре — получишь NameError.
Контроль над автоматизацией:
Нигде нет кода, который сам решит пора запускаться. Каждый этап инициируется только твоим ручным вызовом функции. Это исключает случайные двойные загрузки данных.

Untitled2 (1).ipynb (Медицинская логика)
Детерминированный алгоритм формирования рекомендаций.
Анализирует тренды, прогнозы моделей, выбирает один из 10 текстовых шаблонов (T1–T10) и отправляет итоговый JSON с рекомендацией обратно на бэкенд.
В последней ячейке скрипт сгенерирует тестовый запрос (test_payload), прогонит его через функцию process_recommendation_request() и автоматически отправит результат на бэкенд через send_request_to_backend().
