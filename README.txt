СТРУКТУРА ФАЙЛА (столбцы):
1. patient_id - ID пациента (559, 563, 570...)
2. file_type - тип данных (training/testing)
3. timestamp - время измерения
4. glucose - уровень глюкозы (мг/дл)
5. basal_rate - базальный инсулин (ЕД/час)
6. bolus - болюсный инсулин (ЕД)
7. carbs - углеводы в еде (г)
8. exercise_duration - активность (мин)
9. exercise_intensity - интенсивность (1-10)
